# 个人学习笔记仓库 (Personal Study Notes Repository)

这是一个用于存放个人学习记录与知识管理的仓库，主要使用 [Obsidian](https://obsidian.md/) 进行日常记录与维护。

## 📁 目录结构

仓库主要包含以下几个方向的学习记录：

- **🎓 学校事务**
  包含大学专业课程的相关笔记、作业与实验报告，例如：
  - 编译原理
  - 大数据技术
  - 软件工程

- **🤖 AI应用开发**
  记录了 AI 应用开发的学习旅程，包括：
  - 各阶段的学习笔记
  - AI 相关技能探索
  - 开发工具配置等

- **🐍 Python学习笔记**
  包含 Python 编程语言的基础学习记录和初步探索。

## 🛠️ 管理工具

本项目推荐使用 **Obsidian** 打开以获得最佳的阅读和编辑体验。
