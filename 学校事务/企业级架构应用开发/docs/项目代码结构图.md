## 核心调用链

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as Vue 前端
    participant API as Spring Controller
    participant S as Service
    participant DB as MySQL
    participant AI as Ollama / Spring AI

    U->>F: 输入一句话发布任务
    F->>API: POST /api/tasks/parse
    API->>S: TaskAiService.parseUserIntent()
    S->>AI: 调用大模型
    AI-->>S: 返回 JSON 结构化任务
    S-->>API: AiParsedTaskDTO
    API-->>F: 展示到表单

    U->>F: 确认发布
    F->>API: POST /api/tasks/publish + JWT
    API->>S: TaskService.createAndPublishTask()
    S->>DB: 查询用户余额
    S->>DB: 扣款
    S->>DB: 插入任务
    API-->>F: 发布成功
```

## 阅读路径建议

1. 先看前端路由：`CODE/front/campus-helper-frontend/src/router/index.js`
2. 再看页面入口：`Login.vue`、`TaskHall.vue`、`PublishPage.vue`、`MyTasks.vue`
3. 后端从 `TaskController.java` 进入业务接口
4. 任务主逻辑看 `TaskService.java`
5. AI 解析逻辑看 `TaskAiService.java`
6. 鉴权逻辑看 `WebConfig.java`、`JwtInterceptor.java`、`JwtUtils.java`
