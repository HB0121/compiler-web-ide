【问题描述】

已知Sample语言的文法已经具有如下语法成分：程序整体结构、常量、变量、函数定义（可带参数）、赋值语句（包括表达式）、if语句、while语句、复合语句等，具体见文末的文法定义。Sample语言为类C语言，如无特殊说明，语义参照C语言。

你需要：
能基于词法分析作业的词法分析程序所识别出的单词，根据给定的文法，进一步完善文法规则，设计并实现语法分析程序，识别出各类语法成分。问题任务包含以下几个方面：

（1）解读给定的文法，根据已经给定的文法，增加如下语法成分的文法定义。

✓ for语句

✓ do-while语句

✓ continue 语法

✓ break 语句

✓ 函数调用语句

（2）根据修改后的文法，设计递归下降子程序，用递归子程序法对文法中定义的所有语法成分进行分析；

（3）为了方便进行自动评测，输入的被编译源文件统一命名为input.txt；输出的结果文件统一命名为output.txt ；结果文件中包含如下两种信息：

1）按词法分析识别单词的顺序，按行输出每个单词的信息（单词本身及行号）。以及一些语法成分的名称。

2）在下列高亮显示的语法分析成分分析结束前，另起一行输出当前语法成分的名字，形如“<FunctionDef>”（注：未要求输出的语法成分仍需要分析）

✓ 函数调用 Call

✓ do-while语句 DoWhileStmt

✓ continue 语法 ContinueStmt

注意，在输出这些语法成分名字的时候，有些需要输出对应的参数。比如：函数定义需要输出函数的名字和返回值类型。

【样例说明】

将每个有意义的语法成分用抽象语法树的形式表示出来。

抽象语法树（Abstract Syntax Code，AST）是语法树的一种简化形式，不像语法树要包含所有文法符号，AST只保留语义结构，是源程序的抽象语法结构的树状表示，树的每个节点都表示源代码中的一种结构。运算符和关键字都作为树的内部结点，运算对象作为树的叶子结点出现。

抽象语法树的构建方法是：对运算符和运算分量都建立一个结点

运算符结点：作为内部结点

运算对象结点：作为叶子结点。

中间的运算分量是带运算符的子表达式，也可以是单个运算对象（常数和标识符），作为运算符结点的的子树的根

不同的结点中包含的信息是不同的，可以用不同的结构来表示。

输出时，每棵子树与父节点的基础上缩进2个空格。

各测试用例内容构成包括：

用例1：算术表达式，覆盖所有运算符和结构

包含：+ - * / 一元负号 - 括号 常量 标识符

用例2：布尔表达式，覆盖所有运算符

包含：|| && == != > < >= <= ! 括号 常量 标识符

用例3：表达式包含所有运算符

用例4：基本语法结构（题目中文法所包含的部分）

全局变量和局部变量的定义，函数的定义和声明，各种运算符，if，while语句

用例5：完整语法结构

包括扩展的所有语法成分，在用例4的基础上还包括for，do-while，continue，break以及函数调用等语句。
