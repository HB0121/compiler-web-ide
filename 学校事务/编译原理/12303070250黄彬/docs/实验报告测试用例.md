## 用例 1：完整编译流水线

文件：`examples/report_tests/01_pipeline_success.c`

覆盖任务：词法分析、语法分析、语义分析、符号表、中间代码、解释执行、LLVM IR、MASM16 汇编、目标代码生成。

操作：
1. 打开该源文件。
2. 点击“运行”。
3. 查看 `Tokens`、`AST`、`Semantic Errors`、`Quadruples`、`Interpreter`、`LLVM IR`、`Assembly`。

预期：
- `Diagnostics` 显示 `No diagnostics`。
- 四元式中包含函数调用 `call add`、循环跳转和 `write`。
- `Interpreter` 中能看到 `builtin write(6)`。
- `Assembly` 中只有一个 `main PROC`，全局常量进入 `.DATA` 段。

## 用例 2：语义错误定位

文件：`examples/report_tests/02_semantic_errors.c`

覆盖任务：语义分析、实时错误标记、下方诊断表。

操作：
1. 打开该源文件。
2. 点击“运行”，或在编辑器中观察实时诊断。

预期：
- `add(1)` 触发参数个数错误 `305`。
- `fixed = 5` 触发常量赋值错误 `309`。
- `y = x + 1` 触发未声明标识符错误 `302`。
- 编辑区对应行出现浅红色错误标记，诊断表显示行号、阶段、错误码和提示信息。

## 用例 4：日志正则识别和 NFA/DFA 展示

文件：
- 日志：`examples/report_tests/04_log_regex.log`
- 正则：`examples/report_tests/04_log_regex_patterns.txt`

覆盖任务：4.1 日志关键信息识别、用户正则输入、NFA 图、DFA 图、DFA 转换表。

操作：
1. 将日志文件内容粘贴到左侧编辑器。
2. 将正则输入框设置为 `(?:\d{1,3}\.){3}\d{1,3}`。
3. 点击“日志识别”。
4. 查看 `Log Extract`、`NFA Graph`、`DFA Graph`、`DFA Table`、`NFA Visual`、`DFA Visual`。

预期：
- `Log Extract` 识别 3 个 IP：`172.16.8.31`、`10.0.0.5`、`192.168.1.20`。
- `NFA Graph` 展示 Thompson 构造片段和状态转移。
- `DFA Graph` 展示子集构造后的 DFA 状态。
- 图像页可通过缩放按钮调整显示比例。

## 用例 5：CFG 与 DAG 局部优化

文件：`examples/report_tests/05_cfg_dag_optimization.c`

覆盖任务：4.4 基本块划分、CFG 构建、DAG 局部优化、优化前后对比。

操作：
1. 打开该源文件。
2. 点击“运行”。
3. 查看 `Quadruples`、`Basic Blocks`、`CFG`、`DAG`、`DAG Optimized Quads`、`CFG Visual`、`DAG Visual`。

预期：
- `Basic Blocks` 中能看到由 `if/else` 产生的多个基本块。
- `CFG` 中显示基本块前驱、后继和跳转边。
- `DAG` 中能看到 `a + b` 的公共子表达式被合并。
- `DAG Optimized Quads` 与原始四元式相比减少重复计算。
