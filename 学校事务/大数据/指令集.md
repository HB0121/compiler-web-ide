在slave1、2、3分别执行指令：
```
service ntpd stop
```

```
ntpdate master
```

```
service ntpd start & chkconfig ntpd on
```

启动与主节点master的时间同步服务

在master执行以下指令可快速启动时间同步服务：

```
/usr/local/sbin/ntp_update
```


之后在master节点，启动Hadoop集群


打开集群
```
/usr/local/sbin/hadoop_cluster start
```

关闭集群
```
/usr/local/sbin/hadoop_cluster stop
```

查看集成进度
```
/usr/local/sbin/hadoop_cluster status
```

http://master:50070（HDFS监控）
