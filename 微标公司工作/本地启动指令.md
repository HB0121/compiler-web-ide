# 本地启动指令

## 0. 基础检查

后端要求使用 JDK 1.8。PowerShell 中先确认：

```powershell
java -version
```

正常应类似：

```text
java version "1.8.0_491"
```

注意：JDK 8 使用 `java -version`，不要用 `java --version`。

如果当前终端里的 `java` 不是 1.8，可以临时使用完整路径启动：

```powershell
D:\02_Development_Projects\Develop\jdk1.8.0_491\bin\java.exe -version
```

## 1. Docker Oracle 数据库

查看数据库容器是否运行：

```powershell
docker ps
```

如果 `oracle11g` 没有运行，启动：

```powershell
docker start oracle11g
```

当前本地 Oracle 信息：

```text
容器名：oracle11g
端口：1521
SID：XE
业务用户：PJBMGL
密码：TKY_pjbmgl_123
```

登录 PJBMGL：

```powershell
docker exec -it oracle11g bash -lc "sqlplus PJBMGL/TKY_pjbmgl_123@XE"
```

退出 SQLPlus：

```sql
exit
```

## 6. 常见问题

### 6.1 Unable to access jarfile

原因通常是 jar 文件名写错。以实际 `target` 目录里的 jar 为准，例如：

```powershell
Get-ChildItem *.jar
```

### 6.2 Java 版本不对

如果日志里出现 `java.base`、`JAXB`、`javax.xml.bind`、`Groovy Java7` 相关错误，先确认当前终端使用的是 JDK 1.8：

```powershell
java -version
```

### 6.3 Oracle XE 不支持分区表

当前 Docker 镜像是 Oracle XE 11g，不支持：

```sql
partition by
```

本地开发需要使用普通表版本的 SQL；如果必须使用真实分区表，需要换支持分区能力的 Oracle 数据库。
