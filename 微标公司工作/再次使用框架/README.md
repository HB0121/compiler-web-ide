# MID_ERP_2026(微标企业内部信息化系统)

本仓库用于公司内部信息化整合使用，未来所有信息化项目都将以此库进行扩展；
所涉及以下业务板块:

| 技术                    | 版本                              | 
| ------------------------|-------------------------| 
| agilefast-api           | 用户资料与权限管理(基础框架)   |        
| agilefast-wms-api       | 仓储管理模块   | 
| agilefast-hrm-api       | 人力资源管理模块   | 
| agilefast-plm-api       | 产品生命周期管理   | 
| agilefast-crm-api       | 客户管理管理   | 
| agilefast-fi-api       | 财务(营收)管理   | 
| agilefast-devops-api       | 研发管理模块   | 
| agilefast-mes-api       | 制造执行系统   | 
| agilefast-scm-api       | 供应链管理   | 
| agilefast-crud-example-api       | 快速开发crud案例   |
