# 智慧园区设备运维管理平台界面操作逻辑说明

本文档用于说明各业务原型界面的操作逻辑、页面跳转关系和状态流转规则。开发时应以需求说明书为主，以本说明作为页面交互实现参考。

统一约定：

1. OPS 业务页面路由统一使用 `/ops` 前缀。
2. OPS 业务接口统一使用 `/ops` 前缀。
3. 巡检任务是异常处理入口，实际创建工单时应以具体异常检查项作为工单来源。

## 1. 首页仪表盘

对应图片：`02-首页仪表盘.png`

页面目标：

1. 展示设备、工单、库存等核心运营概览。
2. 帮助用户快速发现异常设备、待处理工单和库存预警。
3. 作为进入各业务模块的快捷入口。

操作逻辑：

1. 页面加载时调用首页统计接口，获取设备总数、在线设备数、故障设备数、今日工单、待处理工单、库存预警等数据。
2. 点击“故障设备”统计卡片，跳转到设备台账页，并自动带入设备状态为“故障”的筛选条件。
3. 点击“待处理工单”统计卡片，跳转到工单管理页，并自动筛选待受理、已分派或处理中的工单。
4. 点击“库存预警”统计卡片或预警列表项，跳转到库存预警页。
5. 点击“最近工单动态”中的某条记录，进入对应工单详情页。
6. 图表支持按接口返回数据渲染，鼠标悬浮时展示分类、数量、占比等信息。

数据联动：

1. 首页统计数据来自设备、工单、库存等模块的聚合接口。
2. 首页只展示汇总信息，不在首页直接修改业务数据。

## 2. 设备台账

对应图片：`03-设备台账.png`

页面目标：

1. 管理园区内所有设备基础信息。
2. 支持设备查询、查看、新增、编辑、删除和状态识别。

操作逻辑：

1. 页面进入时默认分页查询设备列表。
2. 用户可按设备名称、设备编号、设备类型、所在区域、设备状态、负责人进行筛选。
3. 点击“查询”后刷新列表，点击“重置”后清空查询条件并回到第一页。
4. 点击“新增设备”进入设备新增编辑页。
5. 点击某行“详情”进入设备详情页。
6. 点击“编辑”进入设备新增编辑页，并回填当前设备数据。
7. 点击“删除”时弹出二次确认，确认后调用删除接口并刷新列表。
8. 设备状态以标签展示，不同状态应有不同颜色，例如正常、故障、维修中、报废。

数据规则：

1. 设备编号应唯一。
2. 删除设备前应判断是否存在未关闭工单。如存在未关闭工单，前端应给出无法删除提示。

## 3. 设备详情

对应图片：`11-设备详情.png`

页面目标：

1. 展示单个设备的完整档案。
2. 关联查看设备维修历史、巡检记录和备件使用记录。

操作逻辑：

1. 从设备列表点击“详情”进入本页。
2. 页面加载时根据设备 ID 查询设备详情。
3. 点击“编辑设备”进入设备新增编辑页，并携带设备 ID。
4. 点击“生成工单”进入创建工单页，并自动带入当前设备信息。
5. 点击“打印二维码”展示二维码弹窗或模拟二维码区域。
6. Tab 切换“基础信息、维修历史、巡检记录、备件使用”时分别加载对应数据。
7. 在维修历史中点击工单编号，可跳转到工单详情页。
8. 在巡检记录中点击记录编号，可跳转到巡检记录详情页。

数据联动：

1. 设备详情与工单、巡检、库存模块存在关联。
2. 设备状态变化应能影响首页统计和设备列表状态展示。

## 4. 设备新增编辑

对应图片：`12-设备新增编辑.png`

页面目标：

1. 新增或维护设备基础资料。
2. 保证设备台账数据完整、规范。

操作逻辑：

1. 从设备列表点击“新增设备”进入新增模式，表单为空。
2. 从设备列表或设备详情点击“编辑设备”进入编辑模式，表单回填已有数据。
3. 必填字段包括设备名称、设备编号、设备类型、所在区域、安装位置、当前状态。
4. 点击“保存”时先进行表单校验，校验通过后提交新增或编辑接口。
5. 点击“保存并新增”时，保存成功后清空表单并停留在当前页面。
6. 点击“取消”返回设备列表或上一页。

校验规则：

1. 设备编号不能为空且不能重复。
2. 保修截止日期不能早于购买日期。
3. 当前状态必须从字典中选择。

## 5. 工单管理

对应图片：`04-工单管理.png`

页面目标：

1. 统一管理故障报修工单。
2. 支持工单查询、创建、分派、处理、审核和关闭入口。

操作逻辑：

1. 页面进入时分页查询工单列表。
2. 支持按工单编号、工单标题、工单状态、优先级、报修人、处理人、创建时间范围筛选。
3. 点击“创建工单”进入创建工单页。
4. 点击“详情”进入工单详情页。
5. 当工单状态为待受理或待分派时，显示“分派”操作。
6. 当工单状态为处理中时，显示“处理”操作。
7. 当工单状态为待审核时，显示“审核”操作。
8. 点击“关闭”时需要二次确认，确认后调用关闭接口。

状态规则：

1. 待受理工单可以进入分派流程。
2. 处理中工单可以更新进度或提交处理结果。
3. 待审核工单可以审核通过或驳回。
4. 已关闭工单不允许继续编辑业务处理内容。

## 6. 工单详情

对应图片：`05-工单详情.png`

页面目标：

1. 展示工单完整信息和处理过程。
2. 支持从详情页进行状态流转操作。

操作逻辑：

1. 从工单列表或首页最近动态进入本页。
2. 页面加载时查询工单详情和工单操作日志。
3. 顶部展示工单编号、标题、状态、优先级和关联设备。
4. 时间线展示工单创建、分派、接单、处理、审核、关闭等操作记录。
5. 点击关联设备可跳转到设备详情页。
6. 根据当前状态展示对应操作按钮，例如分派工单、更新进度、提交结果、审核通过、关闭工单。

状态联动：

1. 每次状态变更后应刷新详情数据和操作日志。
2. 工单状态变化应同步影响首页统计、设备详情维修历史和工单列表。

## 7. 创建工单

对应图片：`13-创建工单.png`

页面目标：

1. 录入故障报修内容。
2. 关联故障设备并生成维修工单。

操作逻辑：

1. 可从工单列表点击“创建工单”进入，也可从设备详情点击“生成工单”进入。
2. 如果从设备详情进入，应自动带入关联设备。
3. 用户填写工单标题、故障类型、优先级、报修人、联系电话、故障描述、期望处理时间等信息。
4. 点击“提交工单”时进行表单校验，校验通过后创建工单。
5. 创建成功后跳转到工单详情页。
6. 点击“保存草稿”时保存为草稿状态或在 Mock 中模拟保存。
7. 点击“取消”返回工单列表或上一页。

校验规则：

1. 工单标题、关联设备、优先级、故障描述不能为空。
2. 期望处理时间不能早于当前时间。
3. 上传图片可作为模拟交互，不要求真实文件服务。

## 8. 工单处理

对应图片：`18-工单处理.png`

页面目标：

1. 让运维工程师填写现场处理过程。
2. 记录故障原因、处理措施、备件使用和最终结果。

操作逻辑：

1. 从工单列表点击“处理”或从工单详情点击“更新进度”进入。
2. 页面展示工单摘要、故障描述、关联设备和当前处理状态。
3. 用户填写故障原因、处理措施、处理结果、现场图片、实际完成时间。
4. 如维修需要使用备件，可在备件使用表格中添加备件和使用数量。
5. 点击“保存进度”时保存当前处理记录，但工单仍保持处理中。
6. 点击“提交处理结果”后，工单状态变为待审核。
7. 点击“申请备件”可跳转到备件库存页或打开备件选择弹窗。
8. 点击“转派工单”可打开转派弹窗，重新选择处理人。

库存联动：

1. 提交处理结果时，如填写了备件使用，应生成备件出库记录。
2. 出库数量不能大于当前库存。

## 9. 工单分派审核

对应图片：`21-工单分派审核.png`

页面目标：

1. 支持运维主管集中处理待分派和待审核工单。
2. 完成工单责任人指定和处理结果审核。

操作逻辑：

1. 左侧工单队列默认加载待受理、待分派、待审核工单。
2. 选中某条工单后，中间展示工单摘要和故障信息。
3. 对待分派工单，主管选择处理人、预计完成时间并填写分派说明。
4. 点击“确认分派”后，工单状态变为已分派或处理中。
5. 对待审核工单，主管填写审核意见并选择审核通过或驳回。
6. 点击“审核通过”后，工单状态变为已完成。
7. 点击“驳回”后，工单状态变为已驳回或退回处理中。
8. 点击“关闭工单”时需要二次确认，关闭后工单归档。

权限要求：

1. 该页面主要面向运维主管。
2. 未具备工单分派和审核权限的角色不应看到分派、审核、驳回和关闭操作。

## 10. 巡检管理

对应图片：`06-巡检管理.png`

页面目标：

1. 管理巡检计划、巡检任务和巡检记录。
2. 支持巡检计划启停、巡检任务跟踪和异常检查项转工单。

操作逻辑：

1. 页面通过 Tab 区分巡检计划、巡检任务、巡检记录。
2. 巡检计划 Tab 支持查询、新增、编辑、启用和停用。
3. 巡检任务 Tab 支持查看待执行、执行中、已完成和异常任务。
4. 巡检记录 Tab 支持查看历史巡检记录。
5. 点击“新增计划”进入巡检计划新增编辑页。
6. 点击任务“执行”进入巡检任务执行页。
7. 点击记录“详情”进入巡检记录详情页。

数据规则：

1. 停用的巡检计划不再生成新的巡检任务。
2. 已完成的巡检任务应生成巡检记录。
3. 只有巡检任务下存在异常检查项时，才允许发起异常转工单。
4. 转工单时应以具体异常检查项作为工单来源，工单字段为 `source_type=inspection_item`、`source_id=巡检检查项 ID`。

## 11. 巡检计划新增编辑

对应图片：`19-巡检计划新增编辑.png`

页面目标：

1. 配置巡检计划的执行周期、巡检区域和设备分类。
2. 为系统生成巡检任务提供基础规则。

操作逻辑：

1. 新增模式下表单为空，编辑模式下回填已有计划。
2. 用户填写计划名称、巡检区域、设备类型、巡检周期、开始日期、执行时间、负责人和启用状态。
3. 用户选择设备分类后，页面可展示该分类下已维护的检查项模板，用于确认本计划将生成哪些检查项。
4. 检查项模板不在巡检计划页面直接维护，应在设备分类检查项模板维护入口中统一维护。
5. 点击“保存计划”时进行表单校验。
6. 保存成功后返回巡检管理页，并刷新巡检计划列表。

校验规则：

1. 计划名称、巡检区域、巡检周期、负责人不能为空。
2. 必须选择设备分类。
3. 所选设备分类下建议至少存在一个启用的检查项模板。
4. 执行时间应符合所选周期。

## 12. 巡检任务执行

对应图片：`14-巡检任务执行.png`

页面目标：

1. 运维工程师执行巡检任务。
2. 填写检查项结果并提交巡检记录。

操作逻辑：

1. 从巡检任务列表点击“执行”进入。
2. 页面展示任务编号、巡检区域、负责人、计划时间和当前状态。
3. 用户逐项填写检查结果，可选择正常、异常或待复查。
4. 若检查结果为异常，应填写异常说明。
5. 点击“保存进度”时保存当前填写内容，任务状态保持执行中。
6. 点击“提交巡检”后生成巡检记录，任务状态变为已完成。
7. 当任务下存在异常检查项时，页面展示“异常转工单”入口。
8. 点击“异常转工单”时，先展示异常检查项列表。
9. 选择具体异常检查项后进入创建工单页面，并带入设备、检查项名称和异常说明。

数据联动：

1. 检查项异常转工单后，巡检记录中应展示关联工单编号。
2. 巡检任务完成后应出现在设备详情的巡检记录 Tab 中。
3. 创建的工单应记录来源字段：`source_type=inspection_item`、`source_id=巡检检查项 ID`、`source_desc=检查项名称 + 异常说明`。

## 13. 巡检记录详情

对应图片：`22-巡检记录详情.png`

页面目标：

1. 查看已完成巡检任务的归档记录。
2. 追踪异常项和关联工单。

操作逻辑：

1. 从巡检记录列表或设备详情巡检记录 Tab 进入。
2. 页面展示记录编号、巡检计划、巡检人、巡检区域、执行时间和巡检结果。
3. 检查项表格展示每项检查结果和异常说明。
4. 如果存在异常项，应在异常汇总区域集中展示。
5. 如果异常已转工单，应展示关联工单编号。
6. 点击“查看关联工单”进入工单详情页。
7. 点击“导出记录”可模拟导出操作。

## 14. 备件库存

对应图片：`07-备件库存.png`

页面目标：

1. 维护维修备件基础信息。
2. 查看当前库存和预警状态。

操作逻辑：

1. 页面进入时分页查询备件列表。
2. 支持按备件名称、备件编号、备件类型、供应商、库存状态筛选。
3. 点击“新增备件”进入备件新增编辑页。
4. 点击“入库”或“出库”进入备件出入库操作页或打开对应弹窗。
5. 点击“库存流水”进入库存流水页。
6. 点击低库存标签或预警数量，进入库存预警页。
7. 表格中展示当前库存、安全库存和库存状态。

库存规则：

1. 当前库存小于安全库存时显示预警。
2. 出库数量不能超过当前库存。

## 15. 备件新增编辑

对应图片：`23-备件新增编辑.png`

页面目标：

1. 新增或维护备件基础资料。
2. 配置安全库存，支撑库存预警。

操作逻辑：

1. 新增模式下填写备件基础信息、库存信息和供应信息。
2. 编辑模式下回填备件已有信息。
3. 点击“保存”时进行表单校验。
4. 保存成功后返回备件库存列表。
5. 点击“保存并新增”时保存当前备件并清空表单。
6. 点击“取消”返回上一页。

校验规则：

1. 备件编号、备件名称、备件类型、单位不能为空。
2. 初始库存和安全库存必须为非负整数。
3. 备件编号不能重复。

## 16. 备件出入库操作

对应图片：`20-备件出入库操作.png`

页面目标：

1. 完成备件入库和出库登记。
2. 保证库存变动可追溯。

操作逻辑：

1. 从备件库存列表点击“入库”进入入库表单。
2. 从备件库存列表或工单处理页点击“出库”进入出库表单。
3. 入库时填写备件名称、入库数量、供应商、入库日期、存放位置和备注。
4. 出库时填写备件名称、出库数量、关联工单、领用人、出库日期和备注。
5. 点击“确认入库”后增加当前库存并生成入库流水。
6. 点击“确认出库”后减少当前库存并生成出库流水。
7. 点击“取消”关闭弹窗或返回库存列表。

校验规则：

1. 入库数量必须大于 0。
2. 出库数量必须大于 0 且不能大于当前库存。
3. 工单维修出库时应关联工单。

## 17. 库存流水

对应图片：`15-库存流水.png`

页面目标：

1. 查看备件库存变动记录。
2. 支持审计入库、出库和库存调整行为。

操作逻辑：

1. 页面进入时分页查询库存流水。
2. 支持按备件名称、备件编号、流水类型、操作人、时间范围、关联工单筛选。
3. 点击“查询”刷新列表，点击“重置”清空条件。
4. 点击“导出流水”模拟导出当前查询结果。
5. 点击关联工单编号进入工单详情页。
6. 点击低库存预警项进入库存预警页。

数据规则：

1. 每次入库、出库、库存调整都应生成流水记录。

## 25. 报表分析

对应图片：`10-报表分析.png`

页面目标：
