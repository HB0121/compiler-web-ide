# 第二课：复利和折现

先记住一句话：

**复利是在问：今天的钱未来会变成多少。折现是在问：未来的钱今天值多少。**

它们是一正一反。

## 1. 复利：现在的钱变未来的钱

公式：

```text
FV = PV × (1 + r)^n
```

其中：

- `FV`：未来值
- `PV`：现值
- `r`：收益率或利率
- `n`：期数

假设你今天有 10,000 元，年化收益率 8%，放 10 年：

```text
FV = 10000 × (1 + 8%)^10
FV ≈ 21589
```

也就是说，10 年后大约变成 21,589 元。

重点不是赚了 11,589 元，而是你要理解：

**收益也会继续产生收益。**

这就是复利。

## 2. 折现：未来的钱折回今天

公式：

```text
PV = FV / (1 + r)^n
```

假设有人说 10 年后给你 21,589 元，如果你的要求收益率是 8%，那它今天值：

```text
PV = 21589 / (1 + 8%)^10
PV ≈ 10000
```

所以金融里说“估值”，本质就是把未来的钱折回今天。

## 3. 利率越高，未来的钱今天越不值钱

比如 10 年后给你 10,000 元。

如果折现率是 3%：

```text
PV = 10000 / (1.03)^10
PV ≈ 7441
```

如果折现率是 10%：

```text
PV = 10000 / (1.10)^10
PV ≈ 3855
```

同样是未来 10,000 元，要求收益率越高，今天价值越低。

这点非常重要，因为它解释了很多现象：

- 利率上升，债券价格通常下跌
- 利率上升，成长股估值容易被压低
- 风险越高，折现率越高
- 折现率越高，远期收益越不值钱

## 4. 金融估值的底层逻辑

金融资产不是“名字”值钱，而是它未来能给你带来的现金流值钱。

债券为什么有价格？

因为它未来会付利息和本金。

股票为什么有价格？

因为公司未来可能赚钱、分红、回购，或者被市场更高价格买走。

房子为什么有价格？

因为它未来能住、能出租、可能升值。

所以金融估值的底层逻辑是：

```text
资产价值 = 未来现金流的现值
```

## 5. 小练习

你有两个选择：

```text
A：现在拿 10,000 元
B：3 年后拿 12,000 元
```

如果你的年化要求收益率是 6%，计算 B 的现值：

```text
B 的现值 = 12000 / (1.06)^3
B 的现值 ≈ 10075
```

B 今天大约值 10,075 元，比 A 的 10,000 元略高。

所以从纯金融角度看，选 B。

但注意：如果你急用钱，或者对方不一定能兑现，那就不一定选 B。

这就是金融里另一个核心：

**现金流、时间、风险必须一起看。**
