# 第一课：金融学到底研究什么

## 课程目标

这一课先不急着学股票、基金、银行和复杂公式。

你要先建立一个总框架：金融学不是单纯研究“怎么赚钱”，而是研究一件更底层的事：

**钱在不同时间、不同风险、不同人之间，应该如何定价和配置。**

这句话就是金融学的入口。

## 1. 金融学的核心问题

金融世界里，几乎所有问题都可以拆成三个判断：

- 这笔钱什么时候发生？
- 这笔钱有多大不确定性？
- 这笔钱应该归谁、由谁承担风险？

比如：

- 买股票：你在用今天的钱，换未来不确定的收益。
- 买债券：你在用今天的钱，换未来相对确定的利息和本金。
- 银行放贷：银行把钱借给别人，同时承担对方不还钱的风险。
- 公司融资：公司把未来的一部分收益或偿付义务，换成今天可以使用的资金。
- 买保险：你用确定的小额支出，转移未来可能发生的大额损失。

所以金融学真正关心的不是“钱本身”，而是：

```text
时间 + 风险 + 现金流 + 定价
```

## 2. 三个关键词

### 时间

今天的 100 元和一年后的 100 元不是一回事。

因为今天的钱可以：

- 立刻消费
- 存起来赚利息
- 投资产生收益
- 应对突发风险

所以金融学的第一个基本概念是：

**货币有时间价值。**

也就是说，越早拿到的钱，通常越有价值。

### 风险

两个项目都承诺一年后给你 110 元，但它们的价值可能完全不同。

比如：

- A 是银行存款，一年后大概率能拿到 110 元。
- B 是创业项目，一年后可能拿到 200 元，也可能一分钱没有。

它们的承诺金额看起来一样，但风险完全不同。

所以金融学的第二个基本概念是：

**收益必须和风险一起看。**

只看收益，不看风险，是金融决策里最常见的错误。

### 定价

股票、债券、房贷、基金、保险、期权，本质上都在问同一个问题：

**这组未来现金流，现在值多少钱？**

所以金融学的第三个基本概念是：

**资产价格来自未来现金流的折现。**

你可以先把它理解成：

```text
金融资产的价值 = 它未来能带来的钱，折算到今天的价值
```

## 3. 金融学的四大模块

### 个人金融

个人金融研究个人和家庭怎么管钱。

典型问题包括：

- 该不该提前消费？
- 信用卡和贷款怎么用？
- 要不要买保险？
- 如何配置股票、债券、基金和现金？
- 养老和长期储蓄怎么安排？

入门需要掌握：

- 现金流
- 复利
- 利率
- 通胀
- 风险承受能力
- 资产配置

### 公司金融

公司金融研究企业如何做财务决策。

典型问题包括：

- 公司要不要投资一个项目？
- 是发债融资，还是发股票融资？
- 公司赚了钱应该分红，还是继续扩张？
- 企业值多少钱？

入门需要掌握：

- 财务报表
- 净现值 NPV
- 内部收益率 IRR
- 资本成本
- 杠杆
- 股权和债权

### 投资学

投资学研究资产如何定价，以及投资组合如何构建。

典型问题包括：

- 股票为什么涨跌？
- 债券价格为什么会受利率影响？
- 基金和 ETF 适合什么人？
- 为什么不能把钱全部压在一个资产上？

入门需要掌握：

- 股票
- 债券
- 基金
- 收益率
- 波动率
- 分散化
- 估值
- 市场有效性

### 金融市场与机构

金融市场与机构研究银行、央行、券商、交易所、保险公司等机构如何运转。

典型问题包括：

- 央行降息为什么会影响股市和楼市？
- 银行为什么能创造信用？
- 金融危机为什么会传染？
- 金融监管为什么重要？

入门需要掌握：

- 银行体系
- 中央银行
- 利率政策
- 货币供给
- 信用扩张
- 金融监管
- 金融危机

## 4. 第一条核心公式

金融学的地基是一个问题：

**未来的钱，现在值多少钱？**

公式：

```text
PV = FV / (1 + r)^n
```

其中：

- `PV`：现值，也就是今天值多少钱
- `FV`：未来值，也就是未来能拿到多少钱
- `r`：利率或折现率
- `n`：期数

例子：

一年后有人承诺给你 110 元，如果市场无风险利率是 10%，那这 110 元今天值：

```text
PV = 110 / (1 + 10%)
PV = 100
```

这说明：

**一年后的 110 元，在 10% 利率环境下，等价于今天的 100 元。**

## 5. 第一课的关键直觉

你暂时不用急着理解所有金融产品，只要先建立这几个直觉：

- 金融不是只研究赚钱，而是研究时间、风险和现金流的定价。
- 今天的钱通常比未来同样金额的钱更值钱。
- 高收益不能单独看，必须同时看风险。
- 所有金融资产，最后都要回到未来现金流。
- 估值的核心动作，是把未来的钱折算到今天。

## 6. 常见误区

### 误区一：金融就是炒股

炒股只是金融世界里很小的一部分。

金融还包括银行、债券、保险、公司融资、个人理财、央行政策、金融监管等大量内容。

### 误区二：收益率越高越好

收益率高，往往意味着风险也高。

真正成熟的金融思维不是问“能赚多少”，而是问：

```text
为了这个收益，我承担了什么风险？
```

### 误区三：价格等于价值

价格是市场当前给出的数字，价值是资产未来现金流折现后的结果。

价格可以短期偏离价值，但长期看，金融资产绕不开现金流。

## 本课小结

金融学的核心是：

```text
在时间和风险之下，为现金流定价，并把资源配置到更合适的地方。
```

你现在只需要记住一个总公式：

```text
资产价值 = 未来现金流的现值
```
